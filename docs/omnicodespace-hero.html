Four lines into one hub

Claude Code

In each repo you enable, a new or resumed session is told what changed since it last looked: commits, changed files, uncommitted work and unmerged branches. A quiet repo costs no tokens.

Codex

In enabled repos, gets the same brief at session start. Runs started here use its sandbox with the network off, so it can't push and its changes stay uncommitted for your review.

Cloud agents

Push an order as a git branch. You approve it here, an agent on this PC runs it, and the report goes back on the same branch.

You

Start an agent on its own branch and folder. When Claude Code tries to push, the run turns amber and waits for Allow push or Refuse.

Session logs show metadata only (title, model, branch, tokens), never the conversation. Last-seen pointers live as git refs under refs/omni/, which a normal push doesn't send.
